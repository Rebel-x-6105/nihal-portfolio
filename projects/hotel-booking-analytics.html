The project

A hospitality analytics case study examining cancellation patterns, booking lead time, pricing, customer behavior and revenue management.

Approach

The repository combines exploratory analysis, published charts, an executive report, an interactive HTML dashboard and Power BI project files.

Tools & materials

  • Python
  • Pandas
  • Jupyter
  • Power BI
  • HTML
  • Tailwind CSS

Current stage

The report analyzes 118,897 validated reservations and reports a 37.1% cancellation rate within that dataset. The chart shown here comes from the project repository.
